
Installation
************

The package *DSPP Reader* is hosted on the `Python Package Index <https://pypi.org/project/dspp-reader/>`_ so it can be installed using pip.

.. code-block::

    pip install dspp-reader

It is recommended to use virtual environments.

Installing for development is very similar.

First clone de repository, make sure you have the correct virtual environment activated, then move to the root folder of
the repository and do:

.. code-block::

   pip install -e .
